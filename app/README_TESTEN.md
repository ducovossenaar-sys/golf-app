# Mijn Golf – eerste werkende versie

## Snel testen op pc
Omdat service workers en PWA-installatie via http(s) horen te draaien:

1. Open een terminal in deze map.
2. Start bijvoorbeeld: `python -m http.server 8080`
3. Open `http://localhost:8080` op je computer.

## Op telefoon testen
Zet deze map op een eenvoudige webhost of start hem op een apparaat in hetzelfde netwerk en open het lokale IP-adres op je Samsung.
Daarna kun je via Chrome > menu > Toevoegen aan startscherm / App installeren de PWA installeren.
