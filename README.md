# Golf App

Persoonlijke golfscore- en analyse-app.

## Doel
Niet alleen scores registreren, maar per slag genoeg data verzamelen om automatisch inzicht te krijgen in:
- tee shots
- approaches
- short game
- putting
- penalties
- clubafstanden en miss-patronen
- ontwikkeling over meerdere rondes

## Fase 1
- Baanbibliotheek
- Tee-set kiezen
- 9/18 holes
- Supersnelle slaginvoer
- Automatisch afgeleide statistieken
- Scorekaart
- Analyse per onderdeel
- Clubstatistieken
- Afstandszones
- Trends over 5/10/20 rondes
- Ronde-evaluatie en trainingsfocus
- Lokale opslag
- Mobiel-first PWA

## Fase 2
- GPS per slag
- Holekaarten
- Automatische slagafstand
- Strokes-gained-achtige analyse
- Bag mapping
- Dispersion/heatmaps
- Persoonlijke caddie
- Garmin/import
- Cloud sync/back-up
