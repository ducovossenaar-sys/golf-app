# Startprompt voor ChatGPT Work

Bouw een mobile-first PWA genaamd "Golf App" voor persoonlijk gebruik.

Gebruik de bestanden in dit project als leidende requirements:
- PHASE1_REQUIREMENTS.md
- DATA_MODEL.md
- UX_FLOW.md
- ROADMAP.md

Belangrijkste ontwerpprincipes:
1. Tijdens een ronde moet invoeren extreem snel gaan.
2. Een standaard slag moet idealiter in circa 2 tikken geregistreerd kunnen worden.
3. Vraag de gebruiker niet om data die uit de geregistreerde slagen kan worden afgeleid.
4. Bewaar vanaf dag 1 iedere slag als aparte entiteit.
5. Baanbibliotheek hoort in fase 1.
6. Mobile first en PWA/installable.
7. Fase 1 gebruikt lokale opslag en moet offline bruikbaar zijn.
8. Houd de visuele stijl premium, rustig en golfgericht: wit/lichtgrijs, donkerblauw, gedempt donkergroen, afgeronde kaarten.

Werk eerst een klikbare fase-1 basis uit met:
- Home
- Ronde
- Analyse
- Clubs
- Mijn spel
- Baanbibliotheek

Begin daarna met het werkende datamodel en de ronde/slaginvoer.
